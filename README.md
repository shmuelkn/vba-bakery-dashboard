# 🍰 Bakery Order & Inventory Management System (Excel + VBA)

## 📋 Overview
This project is a full inventory and order management system for a fictional bakery, built entirely in Microsoft Excel using advanced VBA scripting, dynamic dashboards, and user forms. It was developed as a project during my studies in Industrial Engineering & Information Systems.

It includes:
- Separate user interfaces for **customers** and **administrators**
- Automated order forms, billing, and email dispatch using Outlook
- Image processing to display products visually
- Inventory management features with real-time stock updates
- Business analytics dashboards: top customers, top-selling products, revenue forecast, and more

## ⚙️ Tools & Technologies
- Excel (.xlsm) + VBA (macros & forms)
- Pivot Tables & formulas
- Outlook integration for email automation
- Embedded product images & responsive interface

## 📸 Features
- 🛒 Customer area: registration, login, product selection, visual ordering
- 🧾 Auto-generated invoices + PDF view + email send
- 🧑‍💼 Admin area: customer management, product catalog, stock control, supplier orders
- 📊 Visual dashboards: sales breakdowns, demand forecasts, customer analysis

## 🧠 Notes
This project was built *before AI tools like ChatGPT were widely available*, requiring hands-on design thinking and real logic-building to simulate a real-world business process. It reflects strong attention to UX and business flow in Excel-based systems.
